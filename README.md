# The Lone Star State
An overview of the state of Texas with subpages about notable cities and a contact form. Utilizes Javascript to dynamically show and hide a dropdown menu when the mouse enters or exits the header, or when focus shifts for keyboard users. Javascript is also used to validate that both emails match in the contact form before submission.

All content was written by me, and all images are stock photos. This repo also has the initial wireframe of this website, as well as an updated wireframe that represents the final design.
